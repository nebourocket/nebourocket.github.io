公開先: https://nebourocket.github.io/

- 書いたもの・いま・リンク

## 更新のしかた

- 英語は HTML に、日本語は `<script>` の `T.ja` に書く。同じ `data-i18n` のキーで両方を直す。
- 「いま」の項目と「最終確認」の日付は、週に 1 回くらい見直す。
- 見た目の決まり: 紙の色の背景、見出しは明朝 (Shippori Mincho B1)、本文は Noto Sans JP、色は青インク `--pen` と金箔 `--foil` の 2 色だけ。全部大文字のラベル・中黒 (·) の区切り・「—」でつなぐ見出し・リンクの「→」は使わない。
